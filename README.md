# SpiritOfTheWoof

**Version:** 1.0.0  
**Author:** noone  
**Release Date:** February 15, 2026

## Description

SpiritOfTheWoof adds a complete line of Druid movement speed buffs to Erenshor, inspired by classic MMO gameplay. This mod introduces four tiers of "Spirit of the Wolf" spells that Druids can cast on themselves or allies to increase movement speed, making travel and exploration more efficient.

## Features

- **Four-Tier Spell Progression** - Lesser, Standard, Greater, and Elder variants scaling from level 5 to 35
- **Increasing Power** - Movement speed bonuses range from 1.5x to 5.0x
- **Extended Durations** - Buff durations from 15 to 60 minutes
- **Vendor Integration** - Spell scrolls purchasable from Tiver Banes (Druid vendor) in Port Azure
- **SimPlayer Interactions** - NPCs can whisper or shout requests for SoW buffs (configurable)
- **Custom Icon** - Unique wolf spirit icon for all spell variants
- **Fully Configurable** - Adjust SimPlayer request frequency via config file

## Installation

1. Install BepInEx for Erenshor (if not already installed)
2. Copy `SpiritOfTheWoof.dll` to `BepInEx/plugins` folder
3. Launch the game
4. (Optional) Copy `the-xorcist.spiritofthewoof.cfg` to `BepInEx/config` folder for preset defaults
